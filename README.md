# Yum Human

A browser-based arcade abduction game created by **Andrew Cole**.

Pilot a UFO, capture targets, fight rival saucers and bosses, earn money, and upgrade your ship between cycles.

## Features

- Automatic desktop/touch control detection
- Mobile D-pad, Beam, Fire, Pulse, Dash, and Pause controls
- Persistent browser save data
- Capture quotas and multi-wave progression
- Rival UFO combat
- Three rotating environments
- Boss battles
- Upgrade shop
- Unlockable Cow Blaster
- Desktop and mobile play

## Controls

### Desktop
- WASD / Arrow Keys — Move
- Space — Beam
- Mouse / Click — Aim and fire
- E — Panic Pulse (when purchased)
- Shift — Dash (when purchased)
- Escape — Pause

### Mobile
- D-pad — Move
- BEAM — Capture
- FIRE — Shoot
- PULSE — Panic Pulse (when purchased)
- DASH — Dash (when purchased)
- Pause button — Pause/resume
